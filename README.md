# Next_word_pred
 ## LSTM Next Word Prediction

A Deep Learning project that uses a LSTM neural network to predict the next word based on the input text.

### Live Demo
https://next-word-pred-1b5w.onrender.com/

### Tech Stack
- Python
- TensorFlow / Keras
- LSTM (Deep Learning)
- Streamlit

### Features
- Takes text input from the user
- Predicts the next word using a trained LSTM model
- Interactive web interface
